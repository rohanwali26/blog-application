# Blog Application

A simple full-stack Blog Application built using HTML, CSS, JavaScript, Node.js, and Express.js.

## Features

- User registration
- User login
- Create blog posts
- Dashboard for viewing blogs
- Backend REST APIs
- Responsive and simple user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Git & GitHub
